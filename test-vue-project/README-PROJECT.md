# Vue 3 Тестовый Проект для Junior/Middle Разработчиков

Это типовой тестовый проект для проверки знаний разработчиков Vue.js уровня Junior/Middle. Проект демонстрирует работу с современным стеком Vue 3 и архитектурой FSD (Feature-Sliced Design).

## 🚀 Технологический стек

- **Vue 3** с Composition API
- **TypeScript** для типизации
- **Vuetify 3** UI компоненты
- **Pinia** для управления состоянием
- **Vue Router** для маршрутизации
- **Vite** для сборки
- **FSD (Feature-Sliced Design)** архитектура

## 📁 Структура проекта (FSD)

```
src/
├── app/                    # Инициализация приложения
│   └── plugins/vuetify.ts  # Конфигурация Vuetify 3
├── entities/               # Бизнес-сущности
│   ├── user/              # Пользователь (типы, модели)
│   └── product/           # Продукт (типы, модели)
├── features/               # Фичи (бизнес-логика)
│   ├── user-management/   # Управление пользователями
│   │   ├── ui/           # Компоненты UI
│   │   └── model/        # Store (Pinia), логика
│   └── product-catalog/   # Каталог продуктов
├── pages/                  # Страницы приложения
│   ├── HomePage.vue       # Главная страница
│   ├── UsersPage.vue      # Управление пользователями
│   └── ProductsPage.vue   # Каталог продуктов
├── shared/                 # Переиспользуемые ресурсы
│   ├── api/              # API клиент (реальный + мок)
│   └── ui/               # Базовые UI компоненты
├── widgets/               # Виджеты (пока не реализовано)
└── processes/             # Процессы (пока не реализовано)
```

## 🎯 Задачи для разработчика

Проект включает типовые задачи, которые проверяются у кандидатов:

### 1. Работа с компонентами Vue 3
- Создание компонентов с Composition API
- Использование TypeScript для пропсов и событий
- Компоненты с разной сложностью (от простых до составных)

### 2. Управление состоянием (Pinia)
- Создание store с состоянием, геттерами и действиями
- Работа с асинхронными операциями
- Интеграция с API

### 3. Работа с формами и валидацией
- Создание форм с Vuetify компонентами
- Валидация полей
- Обработка отправки форм

### 4. Маршрутизация (Vue Router)
- Настройка маршрутов
- Ленивая загрузка компонентов
- Навигация между страницами

### 5. Работа с API
- Создание API клиента
- Обработка ошибок
- Мокирование данных для разработки

### 6. UI/UX с Vuetify 3
- Использование компонентов Vuetify
- Адаптивный дизайн
- Темы и кастомизация

## 🛠️ Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для production
npm run build

# Превью собранного проекта
npm run preview
```
