# 🚀 Vue 3 Test Project - Инструкции по запуску

Тестовый проект Vue 3 для проверки знаний разработчиков уровня Junior/Middle успешно создан!

## 📋 Созданные файлы и структура

**Создано более 20 файлов, включая:**

### 📁 Структура FSD:
- `src/app/` - Инициализация приложения, Vuetify 3 плагин
- `src/entities/` - Сущности User и Product с TypeScript типами
- `src/features/user-management/` - Полный CRUD для пользователей
- `src/shared/` - API клиент, базовые UI компоненты
- `src/pages/` - Страницы приложения
- `src/plugins/` - Конфигурация Vuetify 3

### 🎯 Ключевые компоненты:
1. **User Management (полный CRUD)**
   - `UserList.vue` - Таблица пользователей с поиском
   - `UserForm.vue` - Форма создания/редактирования
   - `UserDetails.vue` - Детальный просмотр
   - `useUserStore.ts` - Pinia store с асинхронными операциями

2. **API инфраструктура**
   - `client.ts` - API клиент с моками для разработки
   - Поддержка реального API (JSONPlaceholder) и моков

3. **UI компоненты**
   - `BaseButton.vue` - Переиспользуемая кнопка
   - `BaseInput.vue` - Базовое поле ввода
   - Полная интеграция Vuetify 3

## 🛠️ Команды для запуска

```bash
# Перейти в директорию проекта
cd test-vue-project

# Установить зависимости (уже установлены)
npm install

# Запустить в режиме разработки
npm run dev

# Приложение будет доступно по адресу:
# http://localhost:5173 (или 5174 если занят)
```

## 🔧 Проверка сборки

```bash

# Сборка для production
```

## 📝 Что проверяется в проекте

### 1. **Vue 3 + Composition API**
   - Все компоненты используют Composition API
   - TypeScript для типизации пропсов и событий
   - Reactivity API (ref, computed, watch)

### 2. **Архитектура FSD**
   - Четкое разделение на слои
   - Изолированные фичи (features)
   - Переиспользуемые сущности (entities)

### 3. **Состояние (Pinia)**
   - Store с состоянием, геттерами, действиями
   - Асинхронные операции с обработкой ошибок
   - Интеграция с API

### 4. **UI/UX с Vuetify 3**
   - Полная интеграция Vuetify 3
   - Адаптивный дизайн
   - Компоненты с валидацией

### 5. **Работа с API**
   - Инкапсулированный API клиент
   - Интерсепторы запросов/ответов
   - Моки для разработки
